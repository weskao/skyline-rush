# Garage VFX Skins — Prebuilt independent vector artwork

These four original transparent SVG category icons are **generated and committed now** so later implementation can reuse them. They are **not yet wired into Vue, the Three.js renderer, inventory, or an item entitlement**.

| File | Purpose |
| --- | --- |
| `thruster.svg` | Exhaust / thruster category |
| `airflow.svg` | Airflow / aerodynamic effects category |
| `nitro-trail.svg` | NITRO trail category |
| `launch-flare.svg` | Launch flare category |

All have transparent root backgrounds, a `96×96` `viewBox`, inline fills/strokes only, accessible SVG titles, no scripts, external fonts, text labels, branding, raster conversion, or painted checkerboard. Icons may be displayed by `<img>` / Vue after feature ownership and exact UI requirements are established. Future integration must test iOS/Android browser and desktop, 1×/2× scaling, contrast, VFX-off/reduced-motion fallback, and Low/Medium/High quality without changing ownership rules. Do not infer finished visual effects from the icon files. Source: original GPT-authored vector artwork for Skyline Rush. No bitmap or AI-generated concept sheet is shipped as a runtime asset.
