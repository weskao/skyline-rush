# Skyline Rush

<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
A playable local 3D racing game inspired by the supplied image of cars lifting over highway traffic with blue thrusters. The user requested TDD and a new local Git repository.

## Capabilities and Constraints
Driving, thruster flight, landing, traffic and a race objective. All game art is original procedural geometry. Flight is fictional arcade handling, not a claim about a real vehicle.

## Stack
Implementation choice: JavaScript, Three.js and Vite; Node's test runner for simulation, Playwright for browser behavior. No backend, accounts or remote runtime assets.

## Working assumptions
Single player, three rivals, one 5 km coastal highway sprint. Desktop keyboard and mobile touch controls. These are implementation defaults, not user-confirmed preferences.
