# Wave 3 試玩商城與裝備揭曉版面

**目標**　讓裝備在解鎖時清楚可見，並讓商城分類、外觀、價格與操作在不同螢幕上容易找到。

**設計**　以 Gran Turismo 7 Brand Central 的展示與購買層級，以及 Forza Horizon 5 Autoshow 與 Garage 的瀏覽分工為參考。保留 Garage 入口，商城內按空間切換側欄和可換行分類。以現有裝備素材做主視覺，點數、金幣、鑽石與商店交易沿用既有流程。

- [Gran Turismo 7 車輛購買](https://www.gran-turismo.com/us/gt7/manual/brandcentral/02)
- [Forza Horizon 5 Autoshow 與 Garage](https://support.forza.net/hc/en-us/articles/4410403589395-How-to-Add-Your-DLC-Cars-to-Your-Garage-on-FH5)

## 驗證紀錄

- 18 項商城 Playwright 測試通過。裝備解鎖在 1440×900、820×1180、390×844、320×568 與 667×320 驗證圖文分區和繼續按鈕的位置。桌機裝備圖從 96 CSS px 增至最高 304 CSS px。
- 實際車庫驗證桌機、平板、手機直向與橫向。模擬直向與橫向摺疊分區，商城和收藏維持在可用分區，兌換解鎖與「繼續」留在商城所在的一側。既有多獎勵切換、減少動態、歷史返回與焦點回歸皆通過。
- `npm test` 通過 3,431 項、跳過 4 項。另驗證型別檢查、模組大小、production 與 trial 建置。
- 繁中畫面與錄影取自試玩建置。擷取時關閉 3D 車輛展示與音訊，使用測試完賽結果作為可重現的試玩餘額。
