- [x] GPU texture compression (KTX-Software → KTX2 / Basis Universal), adopted when Task 4 chose baked textures (owner, 2026-11-07).
  Why: PNG/JPEG decode to uncompressed RGBA8 in GPU memory (1024² + mips ≈ 5.3 MB each); KTX2 transcodes on the device to a GPU-native block format (ASTC/BC7/ETC2, ≈ 1.3 MB each with mips — estimate from 8 bpp blocks, not measured), so VRAM and upload time drop and no CPU image decode runs.
  Encode: `scripts/assets/optimize-glb.mjs` calls `gltf-transform uastc|etc1s`, which shells out to KTX-Software `ktx` (v4.4+, Homebrew `ktx-software`; not an npm dependency). One pass per texture slot, before meshopt: UASTC `--level=2 --zstd=18` for linear data maps (normal, occlusion + `--rdo`, metallicRoughness), ETC1S for sRGB colour maps (baseColor, emissive). Tests: `tests/optimize-glb-steps.test.js`.
  Validate: `scripts/assets/check-glb.mjs` reads each KTX2 header without a GPU: max texture size against `budgets.textureMaxPx`, DFD transfer function (colour slots sRGB, data slots linear). Tests: `tests/check-glb-textures.test.js`.
  Runtime: one `KTX2Loader` per world on the existing `WebGLRenderer` (`createKtx2Provider` in `src/garage-model.ts`, `detectSupport(renderer)` picks the GPU format), loaded only when a manifest entry lists `'ktx2'`; transcoder `public/basis/` is a verbatim copy of three 0.186.1 `examples/jsm/libs/basis/` (Apache-2.0), drift-checked by `tests/model-ktx2-provider.test.js`; no transcoder → `decoder-unavailable` → procedural fallback.
  Evidence: `roadster2` normal + AO ship as UASTC KTX2 (`c75e628e`, `c81dbb50`, `d3deda61`): main GLB 1,383,800 B, low LOD 485,732 B (512 px), both `check-glb` PASS (`9456ff87`); real WebGL Garage load on desktop and phone viewports, model browser specs 15/15.
