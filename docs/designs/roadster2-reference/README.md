# Roadster 2 reference images

Third-party press/event photos of the 2026 Tesla Roadster 2, collected 2026-11-03 as **artistic
reference only** for the player-car mesh (`src/car-model.js`, `src/roadster-fidelity.js`). Not
OEM CAD, not shipped in the bundle, not for runtime use. Spec:
`docs/superpowers/specs/2026-11-03-roadster2-vehicle-fidelity-design.md`.

| File | Use for |
| --- | --- |
| `05-front-nose-light-blade` | Front fascia, triangular lamp pockets, light blade, splitter |
| `09-front-quarter-roadster-logo` | Wedge nose, shoulder fold, glazed roof, five-blade wheel |
| `15-front-quarter-track` | Front three-quarter proportions, wheel/arch, side glass |
| `14-side-profile-road-mode` | Side profile, roofline, wheelbase |
| `07-front-top-lowres` | Plan view of nose/canopy (low resolution) |
| `11-top-front-gullwing-open` | Plan view, bronze canopy glass, gullwing doors |
| `03-rear-quarter-gullwing-open` | Rear quarter, shoulder, door cut, wheel face |
| `01-rear-fascia-quad-thrusters` | Rear light blade, plate recess, quad thrusters, diffuser |
| `02-rear-corner-wheel-diffuser` | Rear corner, carbon pod, wheel spokes |
| `06-rear-quarter-wing-stage` | Deployed wing, continuous rear light, diffuser |
| `04-rear-wing-deployed` | Wing struts, wing planform, corner light pocket |
| `08-rear-quarter-road-lowres` | Rear quarter in road mode (low resolution) |
| `13-rear-flight-thrusters` | Thruster fire / flight rear views |
| `10-flight-underside-lowres` | Flight attitude (low resolution) |
| `12-suspension-weight-control` | Marketing screenshot, not a dimensional input |
